# Starter Food Catalog

The initial catalog contains generic foods with values per 100 g. Values are rounded reference values based on generic entries in USDA FoodData Central's SR Legacy/Foundation collections; raw and cooked forms are separate products. Food composition varies by variety and preparation, so catalog values are estimates rather than product-label guarantees.

Source: [USDA FoodData Central](https://fdc.nal.usda.gov/). USDA requests attribution when its public-domain data is reused.
